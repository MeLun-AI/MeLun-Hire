# MeLun Brand Logo Assets

This pack contains the MeLun ML leaf monogram (without the wordmark).

## Files
- `logo/melun-logo-transparent.png` — primary transparent logo for websites and design work.
- `logo/melun-logo-white-background.jpg` — white-background presentation version.
- `favicon/melun-icon-512.png` — high-resolution square app/icon asset.
- `favicon/melun-icon-192.png` — common web app icon size.
- `favicon/melun-icon-64.png`, `32`, `16` — small icon sizes.

## Brand palette (approximate visual guidance)
- Deep teal green: `#006B5B`
- Forest green: `#08734B`
- Leaf green: `#79B92E`
- Warm orange: `#FF7418`
- Golden yellow: `#FFB91F`

## Usage
Use the transparent PNG over light or dark backgrounds after checking contrast.
Keep the leaf detached and preserve clear space around the complete monogram.
Do not stretch, recolor, rotate, or separate the M and L forms.


## Original wordmark variants
The `logo/original-wordmark-variants/` folder contains the four PNG variants from the ZIP supplied by the user, preserved unchanged: full-color, black, white, and on-dark. These are the original wordmark artwork and are kept separate from the newer standalone ML monogram.
