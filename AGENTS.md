# AI Hiring Tool — Project Instructions

## Project Overview

AI Hiring Tool with HR and Applicant portals.

## Backend

- Python and FastAPI
- SQLite database
- Keep routers modular
- Maintain existing API routes
- Preserve existing API response formats
- Do not change database schema without asking first
- Do not remove existing features unless explicitly requested

## Frontend

- Flutter
- Material 3 design
- Responsive layouts
- Keep HR and Applicant flows separate

## Coding Rules

- Read existing code before editing
- Keep functions small and readable
- Avoid duplicate logic
- Add comments for major sections only
- Preserve backward compatibility
- Handle errors safely
- Do not expose passwords, API keys, or email app passwords in code
- Use environment variables for secrets when possible

## AI Agent Rules

- Explain which files will be changed before making major multi-file changes
- Ask before deleting files, changing schemas, or renaming API routes
- Do not rewrite unrelated code
- Prefer minimal, targeted fixes
- Test affected endpoints after backend changes

## Priority

Readability > Maintainability > Cleverness
